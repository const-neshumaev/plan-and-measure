# Plan & Measure

Android-приложение для лазерного дальномера **Instrumax Sniper 80 Plus**. Цель — принимать измерения по Bluetooth, привязывать их к фотографиям и схемам помещения, сохранять проекты.

Публичного описания протокола Instrumax не существует: он восстановлен экспериментально. Методика исследования, подтверждённые факты и журнал экспериментов собраны в `docs/protocol-research/`.

Измерения можно вводить вручную: дальномер не обязателен и лишь ускоряет ввод. Списки измерений с комментариями сохраняются локально и доступны для открытия при следующем запуске.

В разделе «Планы» контур помещения рисуется пальцем прямо на экране: концы линий ложатся на узлы сетки, вблизи углов, кратных 45°, линия выравнивается точно по ним, а в остальных направлениях сохраняет нарисованный наклон; узлы цепляются друг к другу. Лист плана растёт, когда узел или новый отрезок вытягивают за его границу. Готовый чертёж можно править: в режиме «Правка» узел перетаскивается со снапом к сетке, линию можно выделить касанием и удалить, а если удержать её и потянуть — она сдвигается целиком, не меняя угла наклона (соседние линии при этом тянутся за ней). Захват узла или линии подтверждается расходящимися волнами и виброоткликом: палец закрывает точку, и без этого не видно, попал ли он. В режиме «Размеры» касание по стене открывает рядом с ней карточку: длину можно ввести вручную или принять с дальномера — пока карточка открыта, новое измерение заменяет значение, а удалить размер можно корзиной в карточке. Стены с размером выделены цветом и подписью; подписи мелких граней появляются при увеличении. Вверху редактора видна плашка подключения дальномера с кнопкой «Подключить». Два пальца управляют видом: щипок меняет масштаб, перетаскивание двигает лист; отдалить можно и сильнее вписанного листа, чтобы вокруг него оставался запас места для протяжки стены за границу; кнопка на верхней панели возвращает вписанный вид. Последнее действие отменяется кнопкой «Отменить». Планы сохраняются локально и открываются снова вместе с чертежом.

## Требования

- Android Studio (актуальная версия) — она принесёт JDK 17+ и Android SDK.
- Телефон с BLE и Android 7.0+ (проверяем на Xiaomi 11T, Android 14).
- Дальномер с включённым Bluetooth-режимом.
- Для Gradle нужен JDK 17–21. Встроенный в новые версии Android Studio JBR 25 не подходит для Gradle 8.7: в Settings → Build, Execution, Deployment → Build Tools → Gradle выберите Gradle JDK 17/19/21 (можно скачать прямо там).

Отдельно ставить Gradle не нужно: версия зафиксирована в `gradle/wrapper/gradle-wrapper.properties`, wrapper уже в проекте.

### SDK

Проект ожидает Android SDK с установленными `Android SDK Platform 34` и `Android SDK Build-Tools 34.0.0`. Если при открытии Android Studio просит путь к SDK, укажите корень SDK (папку, в которой лежат `platforms`, `build-tools`, `platform-tools`). Затем в SDK Manager установите платформу 34 и Build-Tools 34.0.0 и примите лицензии.

## Сборка

1. Открыть папку проекта в Android Studio.
2. Дождаться Sync: Studio сама скачает Gradle 8.7 и зависимости, при необходимости предложит установить Android SDK Platform 34 и Build Tools.
3. Запустить на телефоне: `Run 'app'`.

Через командную строку (нужны JDK 17–21, Android SDK и env `JAVA_HOME`, указывающий на этот JDK):

```
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

## Данные

Списки измерений хранятся только на устройстве, в `filesDir/measurements/<uuid>.json`. Сервера и аккаунтов нет. Каждое изменение сразу записывается атомарно, предыдущая версия документа остаётся в `.bak`. Подробности и причины — в `docs/adr/0002-local-json-documents-for-measurement-lists.md`.

Планы хранятся так же, в `filesDir/plans/<uuid>.json`. Координаты чертежа — абстрактные единицы сетки, а не пиксели, поэтому план одинаково выглядит на разных устройствах и в разной ориентации. Размер листа хранится в документе и растёт по мере рисования, а зум и сдвиг вида в файл не попадают и при открытии сбрасываются. Длина стены хранится на грани строкой и в той единице, в которой введена или получена с дальномера: масштаба у плана пока нет, поэтому размер — пометка, а не геометрия. Формат — `docs/adr/0004-store-plans-as-local-json-documents.md`, лист и вид — `docs/adr/0006-plan-sheet-in-document-view-on-screen.md`, размеры — `docs/adr/0007-plan-dimensions-on-edges.md` и `docs/adr/0008-plan-dimensions-mode.md`.

`allowBackup` выключен: при переустановке данные пропадут. Экспорт и резервное копирование появятся отдельной задачей.

Дальномер не обязателен: значения вводятся вручную в любом списке. Кадры с прибора записываются только пока открыт редактор списка, приложение на переднем плане и запись не поставлена на паузу — см. `docs/adr/0003-measurements-are-independent-of-ble-session.md`. В плане кадры попадают только в карточку размера открытой стены и только пока приложение на переднем плане.
