# 0019. Вложенные карточки и «Без проекта» по умолчанию

- Статус: Superseded by 0024
- Дата: 2026-11-28

## Контекст

[0016](0016-selectable-project-tree-layout.md) выбрал раскладкой дерева по умолчанию заголовки
групп: на глубоких ветках они оставляют ширину для длинных имён. После появления вложенных
карточек с направляющими и подрезки карточек по правому краю вложенный вид стал основным рабочим:
он лучше показывает глубину, а правая граница больше не «пляшет».

Разделы «Измерения» и «Планы» по умолчанию показывали все объекты, включая входящие в проекты.
По замыслу проект должен разгружать общие списки, поэтому новый охват «Без проекта» лучше подходит
как исходное состояние.

Оба значения хранятся в `AppSettings` и `SettingsStorage` и сохраняются при первом запуске, как и
остальные настройки.

## Решение

- `AppSettings` по умолчанию: `ProjectTreeStyle.Nested` и `ObjectScope.WithoutProject`.
- `SettingsStorage` использует эти значения, когда настройка ещё не сохранена.
- Существующие сохранённые значения не перезаписываются: у тех, кто уже открывал приложение,
  остаётся прежний выбор, включая автоматически сохранённые старые значения по умолчанию. Сменить
  вид можно в настройках.
- Отдельная миграция для переноса старых значений по умолчанию не делается. Если понадобится
  принудительно перевести всех на новые значения, это будет отдельное решение с версией настроек.

## Последствия

- Новые установки открывают дерево во вложенных карточках и не показывают в разделах объекты,
  входящие в проекты.
- Для действующих установок поведение не меняется само по себе; это защищает явный выбор
  пользователя от неожиданной перезаписи.
- Значение по умолчанию из 0016 заменено для новых установок; сама возможность выбирать раскладку
  остаётся.
- Охват объектов стал отдельной настройкой в этой итерации; его значение по умолчанию теперь
  «Без проекта».

## Альтернативы

- **Оставить старые значения по умолчанию.** Привычнее для существующих установок, но новый вид и
  разгрузка разделов созданы именно как основной сценарий.
- **Принудительно перезаписать настройки при обновлении.** Даёт всем новый вид сразу, но стирает
  явный выбор пользователя и требует версии настроек и миграции.
