# 0016. Выбирать раскладку дерева проекта в настройках

- Статус: Accepted
- Дата: 2026-11-22

## Контекст

Дерево проекта показывает папки и ссылки на списки и планы ([0015](0015-projects-as-reference-trees.md)).
При глубине три-четыре уровня вложенность читалась плохо: все строки были одинаковыми
карточками с общим левым краем, а глубину выдавал только сдвиг текста на 20 dp.

Обсуждены два рабочих представления:

- **заголовки групп** — папка рисуется плашкой-заголовком, объекты — обычными строками с
  разделителями внутри группы;
- **вложенные карточки** — строки ужимаются с обеих сторон по глубине, а уровень показывают
  направляющие линии предков.

Оба варианта решают задачу, но по-разному расходуют ширину экрана и по-разному читаются на
разных проектах. Проверить это можно только на реальных данных и на телефоне, поэтому выбор
нельзя сделать один раз и навсегда в коде.

## Решение

- Раскладка хранится в `AppSettings` как `ProjectTreeStyle`: `Headers` (по умолчанию) и
  `Nested`.
- Значение сохраняется в `SettingsStorage` рядом с темой и языком и переключается в разделе
  «Настройки».
- Обе раскладки рисуют одни и те же строки `ProjectTree`; различаются отступы, цвет и
  типографика. Действия над папками и объектами общие.
- По умолчанию включены заголовки групп: на глубоких ветках они оставляют ширину для длинных
  имён.

## Последствия

- Экран дерева содержит две ветки представления, и любое изменение строк нужно проверять в
  обеих.
- Настройка не влияет на данные и на структуру проекта; смена раскладки не пересоздаёт
  Activity (в отличие от языка) и не пишет документы.
- Для тех, кто уже пользуется приложением, вид по умолчанию не меняется: `Headers` — текущая
  раскладка.
- Если одна из раскладок окажется лишней, её удаление оформляется новым ADR и миграцией
  настройки.

## Альтернативы

- **Оставить одну раскладку.** Проще в поддержке, но выбор был бы сделан без проверки на
  реальных проектах.
- **Адаптивная раскладка по глубине** (после N уровней переключаться на заголовки). Порог N
  неочевиден, а поведение меняется само по себе и непредсказуемо для пользователя.
- **Отдельная тема или режим «компактно».** Смешивает визуальный стиль всего приложения с
  частной задачей дерева.
