# 0024. Всегда скрывать объекты проектов в разделах

- Статус: Accepted
- Дата: 2026-11-28

## Контекст

Настройка «Объекты в разделах» предлагала охват «Все / Без проекта»: с «Все» списки измерений,
планов и съёмок показывали и объекты, входящие в проекты, с меткой проекта. На практике выбор
сбивает с толку: пользователь не понимает, почему один и тот же объект виден то в разделе, то
только в дереве, и зачем ему вообще видеть проектные объекты в общем списке. Гибкость не
востребована, а проект задуман как место, где объекты разложены по папкам и не мешают общим
разделам ([0015](0015-projects-as-reference-trees.md)).

Ранее [0019](0019-default-nested-cards-and-project-scope.md) выбрал охват «Без проекта» только
значением по умолчанию и оставил выбор пользователю. Теперь выбор убирается совсем.

## Решение

- **Настройки охвата больше нет.** `ObjectScope`, поле `AppSettings.objectScope`, ключ
  `object_scope` и карточка в настройках удаляются. Сохранённый ключ игнорируется: отдельная
  миграция не нужна, потому что удаление настройки не меняет документы.
- **Разделы всегда показывают самостоятельные объекты.** Списки измерений, планов и съёмок
  фильтруют объекты, на которые ссылается любой проект. Проектные объекты видны только в дереве
  проекта.
- **Фильтр общий, документы не меняются.** Владение объектом остаётся прежним: проект хранит
  только ссылки, а раздел лишь не показывает объект, входящий в проект
  ([0015](0015-projects-as-reference-trees.md)).
- **Бейдж проекта в списках удаляется.** После фильтрации он не может появиться; список получает
  только множество идентификаторов объектов, занятых проектами, а имя проекта по-прежнему
  разрешается в диалоге добавления объекта в дереве.
- **Раскладка дерева остаётся настраиваемой.** Значение по умолчанию — вложенные карточки, как
  решил 0019; карточка настройки называется «Вид дерева проекта», чтобы было ясно, что она меняет
  только представление дерева.

## Последствия

- В настройках становится на одну непонятную опцию меньше; поведение разделов одинаково у всех.
- Объект, добавленный в проект, исчезает из своего раздела. Это ожидаемо: вернуть его можно,
  исключив из проекта или открыв из дерева.
- Пользователи, выбравшие охват «Все», теряют этот вид. Решение осознанное: гибкость не окупала
  путаницу.
- Удаляются мёртвые ветки: бейдж «В проекте: …» в трёх списках и хранение охвата в настройках.
- Форматы документов не меняются, `schemaVersion` не повышается.

## Альтернативы

- **Оставить настройку и только переименовать её.** Не решает главную проблему: пользователь всё
  ещё должен понимать разницу между двумя режимами.
- **Оставить «Без проекта» по умолчанию и скрыть опцию.** Поведение то же, но в настройках
  остаётся неиспользуемый ключ и код; проще убрать совсем.
- **Показывать проектные объекты в разделах с фильтром по проекту.** Даёт больше контроля, но
  усложняет разделы и дублирует дерево проекта.
- **Скрывать проектные объекты только в «Измерениях» и «Планах».** Съёмка ведёт себя так же, как
  остальные объекты; отдельное правило снова пришлось бы объяснять.
